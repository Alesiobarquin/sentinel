hashed operator helpers, retained here as text snapshots with their manifest.
They are inspection records, not commands to execute from this directory. The
current stock CLI incorporates the international-checkout driver and real prior
Jaeger inventory capture; those changes are later than the evaluated source.

in the adjacent recovery/method records. The rejected shipping checks, collector
inventory timeout audit, and Kafka before/after restart records are included.

has no capture output. No rejected corpus was supplied to an evaluated model.

error types. Request bodies, fixture card details, and credentials are excluded.

not a constant-arrival load benchmark.

exact observed inventory provenance. The latter has generic freshness wording;
it does not tell the model which fault was injected. The public per-run inventory
projection keeps service names, so this separate record preserves the omitted
provenance. This is capture preparation, not an agent telemetry cache.

budget stop after a successful read. It is outside the 48-attempt accuracy study.
